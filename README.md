# 本体论学习与采购 Demo

可运行的采购教学示例在 `demo/ontopilot_supplier/`。教学数据已包含在仓库里。克隆后按该目录的 README 安装依赖，并在 `.env` 中填写你自己的 DeepSeek API Key。

页面能做什么、三个账号分别有什么权限，见 `demo/ontopilot_supplier/功能说明.md`。

本体概念说明见 `Palantir本体论_入门介绍.md`。

`repos/ontopilot/` 是运行这个 Demo 所需要的 [jingw2/ontopilot](https://github.com/jingw2/ontopilot) 代码，已去掉测试目录。它不是 Palantir 官方产品。
