# 本体论学习与采购 Demo

可运行的采购教学示例只在 `demo/ontopilot_supplier/`。教学数据、页面和运行所需代码都在这个目录里。克隆后按该目录的 README 安装依赖，并在 `.env` 中填写你自己的 DeepSeek API Key。

页面能做什么、三个账号分别有什么权限，见 [features.md](demo/ontopilot_supplier/features.md)。

本体概念说明见 [ontology-introduction.md](ontology-introduction.md)。

其中的 `ontopilot/` 与 `api/` 来自 [jingw2/ontopilot](https://github.com/jingw2/ontopilot)，已放进采购示例目录，供本机直接运行。它不是 Palantir 官方产品。
